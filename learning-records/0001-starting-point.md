# Starting point established: beginner, deep-mastery, framework-first

Learner self-rates as a **beginner** in system design — core building blocks
(caching, sharding, consistency, queues) are still fuzzy and they have not driven
structured design interviews. Target is **L6/L7 (staff+) at FAANG**, with **no
deadline**, so we optimize for durable depth over speed.

Chosen entry point: **the delivery framework first**, then core concepts, then
case studies easy → hard. This sets the floor for the ZPD: future lessons can
assume the 6-step framework as shared vocabulary but must NOT assume any building
block (DB internals, CAP, hashing) until taught and demonstrated.

Implication: every lesson carries an explicit "what moves this to staff-level"
callout, since the gap between this learner's current level and the L6/L7 target
is large and the staff signal (40/60 depth, proactivity, simple-by-default) must
be trained deliberately from the start rather than bolted on later.
